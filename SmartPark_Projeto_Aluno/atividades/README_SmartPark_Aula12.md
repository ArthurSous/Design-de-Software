# SmartPark — Aula 12

## Tema
C4, UML, sequência e Architecture as Code

## Situação do projeto
O SmartPark contém decisões e artefatos legados possivelmente incompletos ou inadequados ao conteúdo desta aula. O aluno deve analisar o estado atual antes de modificar.

## O que o aluno deve fazer
1. produzir C4 Contexto/Contêiner;
2. refinar UML seletiva;
3. modelar sequência de entrada ou saída/pagamento;
4. versionar fontes Mermaid/Structurizr.

## Dicas
- Escolha cenário crítico.
- O diagrama deve corresponder ao estado atual.

## Evidências mínimas
- Issue `Aula 12`;
- branch sugerida `aula-12`;
- commits explicativos;
- README/Markdown com problema observado, alteração realizada e critério de aceitação;
- evidência de compilação/teste quando houver código;
- PR ou revisão equivalente quando aplicável.

## Prazo operacional
O trabalho deve começar em sala e ser concluído até o início da aula seguinte, salvo orientação diferente do professor.

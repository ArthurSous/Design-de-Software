# Requisitos iniciais — legado

1. O sistema deve controlar vagas disponíveis.
2. Deve permitir reservar vagas.
3. Deve registrar entrada e saída de veículos.
4. Deve calcular a cobrança corretamente.
5. Deve aceitar diferentes meios de pagamento.
6. Deve integrar com sensores.
7. Deve controlar cancelas.
8. Deve notificar usuários.
9. O sistema deve funcionar rapidamente.
10. Deve ser fácil integrar novos equipamentos.

Os requisitos não possuem critérios de aceitação suficientes.
